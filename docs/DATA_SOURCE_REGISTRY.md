# Data source registry

Statuses mean: **registered** = access route and dataset documented; **operational** = real data ingested and queryable; **validated** = checked against independent documented measurements or reference examples. Operational does not imply scientific analogue validity.

Copernicus source description: [Planetary Computer Copernicus DEM collection](https://planetarycomputer.microsoft.com/dataset/group/copernicus-dem). The collection describes GLO-30 as a near-global, approximately 30 m digital surface model based on TanDEM-X radar observations. The app indexes only the selected 10.19 km contexts listed in sidecars; do not infer global app coverage from the upstream dataset's nominal extent. The MOLA source page describes its MEGDR grid products and the per-bin count layer used to distinguish measured from interpolated cells.
