# Submission recovery status

This is a working snapshot, not a claim of scientific validation or final submission acceptance.

- The completed index release `fa192df2f8090855b8f018daeac13c62cec33439cd5fd38c668241cabb2f1df3` contains 2,273 Earth, 7 Moon and 13 Mars contexts (2,293 total). It incorporates all 1,000 bounded global GLO-90 contexts. The precomputed SQLite file is 26,435,584 bytes.
- In the earlier `46ede1a0` snapshot, geographic balance remained limited: 1,215 of 2,065 Earth context centers (58.8%) fall within a broad Australia bounding box (10–45°S, 110–155°E). This is a coordinate approximation, not a national-boundary classification. That snapshot contained 1,165 NASADEM, 792 GLO-90 and 108 GLO-30 contexts; it is not globally exhaustive or representative.
- In release `fa192df2`, the same broad bounding box contains 1,225 of 2,273 Earth centers (53.9%). The 1,000 new contexts occupy all 18 ten-degree latitude bands and all 12 thirty-degree longitude bands, with 51 of the 216 combined bins empty and sparse polar bands. Their summed nominal footprint area is 103,796 km²; 87,068 km² has complete WorldCover classification and 81,471 km² maps to non-water classes. These footprints are disconnected samples, not global coverage. The sampler read 3,131,635,118 source bytes and retained 10,486,338 bytes of generated windows and metadata (10,486,616-byte sampled output peak); land-cover statuses were 839 available, 111 partial and 50 unavailable.
- The all-dimension reference comparisons currently support terrain, terrain-dependent operations, and experimental mapped-material overlap for some named places. Five other dimension comparators require matched observations that are not yet indexed; their scores are unavailable. The methods and exact gaps are documented in [the evidence matrix](EIGHT_DIMENSION_INPUTS.md).
- In the local catalogue comparison of the Mare Tranquillitatis pit with the Mojave lava-tube region using equal dimension weights, the experimental mapped-material score is 1.0, terrain 0.539 and terrain-derived operations 0.646; the partial combined index is 0.796 with 25% weighted evidence completeness. This indicates broad interpreted group overlap only. The map scales differ and operations shares terrain evidence. The five other dimensions have no comparable indexed evidence for this pair. A focused browser test selected the lunar pit, chose the geology profile, and displayed the Mojave mapped groups, map scales and source links.
- A local API trace resolved and ranked the Shackleton and Aeolis windows and correctly reported an uncovered Mars coordinate. On the earlier `02baecd1` snapshot, ten-result all-dimension responses were 255,436 and 212,226 bytes, respectively. A warm three-sample Aeolis TestClient benchmark had 731 ms median HTTP time; it excludes browser rendering and network transport.

The latest browser run passed all 18 tests against release `fa192df2`, including automatic Earth focus, the real mapped-material comparison, shared operations explanation, Moon/Mars discovery, out-of-coverage handling, and stale-response protection. DINOv2 and Terrain checks require ranked observations with the corresponding evidence labels. Focused follow-up checks cover context details, payload bounds, tie-list limits, and land-cover bounds; the latest API and scoring run passed 38 tests.
- A continuation monitor conservatively charged the full task-specific browser cache and sampled a peak of 645,742,592 bytes above the repository baseline. Other temporary files and between-sample peaks were not measured; this does not prove the 5 GB hard limit across the entire task.
- No independently reviewed analogue relevance set, DEM cross-source calibration, vehicle safety assessment, or live provider availability guarantee is established.

Reproduce from the repository root with `uv sync --locked --extra dev`, `uv run python scripts/build_feature_index.py`, `uv run uvicorn twinworld.api:app --reload`, then run `npm ci` and `npm run dev` in `apps/twinworld`. Use `uv run pytest -q`, `uv run ruff check .`, `uv run mypy src/twinworld`, `npm run build`, and `npm test` for the requested gates. The index build uses only available local artifacts; a fresh checkout may have fewer contexts. See [reproducibility](REPRODUCIBILITY.md) and [autonomous discovery](AUTONOMOUS_DISCOVERY.md) for source acquisition and limits.

To emit the local HTTP comparison trace and warm timings, run:

```sh
uv run python scripts/submission_demo.py > /tmp/enom-submission-demo.json
uv run python scripts/benchmark_discovery.py --samples 20
uv run python scripts/benchmark_discovery.py --context-id lola_polar_moon_shackleton_rim --samples 20
uv run python scripts/assess_dem_source_sensitivity.py
```

The trace includes detailed source context and can be large. Inspect the returned release identity before comparing it with a previous run. These commands use the local index; they do not rebuild it or make a scientific validity claim. Browser tests require an installed Playwright Chromium, or an explicit `ENOM_BROWSER_PATH` pointing to a compatible local Chromium executable.
